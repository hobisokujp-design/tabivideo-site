プライバシーポリシー / Privacy Policy

日本語

tabivideo は、作者本人が自分の YouTube チャンネルへ動画をアップロードするために使う、個人用の道具です(一般には配っていません)。このページは、tabivideo が Google・YouTube のどんな権限と情報を使うかを説明します。

使う Google の権限

  • YouTube Data API の youtube.upload と youtube。
  • 目的は、自分のチャンネルへの動画のアップロード・サムネイルの設定・公開の設定だけです。

得る情報と保存の場所

  • 許可のトークン: 作者の PC の中だけに保存します。外へ送らず、第三者と共有しません(YouTube Data API を呼ぶ時に Google へ送る場合を除きます)。
  • アップした動画の ID と URL: 作者の PC の中の記録だけに残します。

他の人の情報

  • 他の人の情報は集めません。
  • 情報を売りません。広告に使いません。第三者に渡しません。

YouTube API Services・Google の方針

  • tabivideo は YouTube API Services を使っています。YouTube 利用規約に従います。
  • Google プライバシーポリシー
  • tabivideo による Google API から受け取った情報の利用と転送は、限定的な使用の要件を含む Google API サービスのユーザーデータに関するポリシーに従います。

許可の取り消し方

Google アカウントのアクセス許可の画面から、tabivideo の許可を取り消せます。

問い合わせ先

GitHub の Issues のページからご連絡ください。

English

tabivideo is a personal tool that the author uses to upload videos to his or her own YouTube channels. It is not distributed to the public. This page explains which Google and YouTube permissions and data tabivideo uses.

Google permissions used

  • YouTube Data API scopes youtube.upload and youtube.
  • The only purposes are uploading videos, setting thumbnails, and setting visibility on the author's own channels.

Data obtained and where it is stored

  • Authorization tokens: stored only on the author's own computer. They are not sent anywhere and not shared with third parties (except to Google itself when calling the YouTube Data API).
  • IDs and URLs of uploaded videos: kept only in a record on the author's own computer.

Other people's data

  • No data about other people is collected.
  • No data is sold, used for advertising, or given to third parties.

YouTube API Services and Google policies

  • tabivideo uses YouTube API Services and is bound by the YouTube Terms of Service.
  • Google Privacy Policy
  • tabivideo's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

How to revoke access

You can revoke tabivideo's access at any time on the Google Account permissions page.

Contact

Please contact me through the GitHub Issues page of this repository.
