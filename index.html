tabivideo

日本語

tabivideo は、私(作者本人)が使うための、個人用の道具です。海外の方の動画を翻訳・編集して作った自分の動画を、自分の YouTube チャンネル(火曜通信・月曜通信)へアップロードするために使います。

  • 自分だけが使う道具で、一般には配っていません。他の人の利用は想定していません。
  • YouTube Data API を、自分のチャンネルへの動画のアップロード・サムネイルの設定・公開の設定のためだけに使います。

プライバシーポリシー

English

tabivideo is a personal tool for my own use. I use it to upload videos that I made myself (translated and edited versions of other creators' footage) to my own YouTube channels (Kayou Tsushin and Getsuyou Tsushin).

  • It is used only by me and is not distributed to the public. It is not intended for use by other people.
  • It uses the YouTube Data API only to upload videos, set thumbnails, and set visibility on my own channels.
